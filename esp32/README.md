# ESP32 Simulator — Wokwi

Firmware simulator untuk Mixer-Online.

- 18 channel
- HTTP health endpoint: /health
- HTTP control endpoint: /control
- Protokol JSON
- Siap menjadi dasar firmware ESP32 fisik

Catatan: Wokwi tidak menyediakan endpoint publik stabil yang bisa langsung dipanggil GitHub Pages. Untuk koneksi web langsung diperlukan bridge/tunnel atau backend perantara. Firmware ini memvalidasi protokol dan alur kontrol terlebih dahulu.
